# تدوير | Tadwir — الموقع التعريفي

> «لنمنح الأجهزة القديمة فرصة لإنقاذ المستقبل»

موقع تعريفي (Landing Page) من صفحة واحدة لشركة **تدوير**، الشركة السعودية الناشئة في إدارة النفايات الإلكترونية بطرق ذكية ومستدامة باستخدام الذكاء الاصطناعي وإنترنت الأشياء.

الموقع ثنائي اللغة: **عربي (RTL)** افتراضياً مع زر **EN** للتبديل إلى **الإنجليزية (LTR)**، ويتذكّر المتصفح اختيار الزائر. ويمكن فتح النسخة الإنجليزية مباشرة بإضافة `#en` إلى الرابط. الموقع متجاوب مع شاشات الجوال (من 360px) والتابلت والديسكتوب، ويعمل على GitHub Pages مباشرة دون أي خطوة بناء (build).

## الأقسام

شريط تنقل زجاجي · Hero بخلفية دوائر إلكترونية متحركة · من نحن (الرؤية والرسالة) · القيم والأهداف · جهاز **TADWIR AI** بنقاط تفاعلية (Hotspots) · كيف يعمل (Timeline) · التقنيات وشارة براءة الاختراع · تطبيق تدوير (موكاب CSS) · الخصوصية والأمان · الحلول والخدمات · أرقام السوق (عدّادات) · الأثر وأهداف التنمية المستدامة ورؤية 2030 · المسؤولية المجتمعية · الخطط المستقبلية · تواصل معنا (حسابات التواصل الاجتماعي) + Footer.

## التقنيات

- HTML5 + CSS3 + JavaScript (Vanilla) — بدون أي Framework.
- [GSAP 3 + ScrollTrigger](https://gsap.com/) من cdnjs للحركات.
- خط **IBM Plex Sans Arabic** من Google Fonts.
- أيقونات SVG مرسومة داخل الصفحة (sprite) وأيقونات أهداف التنمية المستدامة مرسومة بـ CSS.
- خلفية الـ Hero مرسومة بـ Canvas وتتوقف تلقائياً عند الخروج من الشاشة.
- احترام `prefers-reduced-motion`: تُعطَّل الحركات الثقيلة ويظهر المحتوى مباشرة.
- إذا تعذّر تحميل GSAP يظهر كل المحتوى بشكل طبيعي دون حركات.

## التشغيل محلياً

لا يحتاج الموقع إلى تثبيت أي شيء. يكفي تشغيل خادم ملفات بسيط من جذر المشروع:

```bash
# باستخدام Python
python3 -m http.server 8080

# أو باستخدام Node
npx http-server -p 8080
```

ثم افتح: <http://localhost:8080>

## النشر على GitHub Pages

1. ارفع الملفات إلى فرع `main` في المستودع.
2. من **Settings → Pages** اختر: Source = `Deploy from a branch`، Branch = `main`، Folder = `/ (root)`.
3. بعد دقيقة تقريباً يصبح الموقع متاحاً على:
   `https://<اسم-المستخدم>.github.io/tadwir-website/`

جميع المسارات في الموقع نسبية (relative)، لذلك يعمل من أي مسار فرعي دون تعديل.

**رابط الموقع المباشر:** `https://<اسم-المستخدم>.github.io/tadwir-website/` ← حدّثه بعد التفعيل.

## بوت تيليجرام: التحكم بالمنتجات وصور «روح الفريق»

### الإعداد (مرة واحدة)

التوكن **لا يُكتب في أي ملف**، لأن المستودع عام وأي أحد يراه يتحكم في البوت. يُحفظ كسرّ في GitHub:

1. في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف `TELEGRAM_BOT_TOKEN` وقيمته توكن البوت.
2. من **Settings ← Actions ← General ← Workflow permissions** اختر **Read and write permissions**.
3. افتح **Actions ← Telegram bot ← Run workflow**.
4. أرسل أي رسالة للبوت. سيرد عليك برقم محادثتك.
5. أضف سرّاً ثانياً باسم `TELEGRAM_CHAT_ID` وقيمته ذلك الرقم. بعدها البوت ينفّذ أوامرك أنت فقط ويتجاهل أي شخص آخر.
6. شغّل **Run workflow** مرة ثانية.

### الأوامر

أرسل `مساعدة` للبوت ليعرضها لك. يمكن كتابة رقم المنتج بدل اسمه.

| ماذا تريد | ماذا ترسل |
|---|---|
| عرض المنتجات بأرقامها | `المنتجات` |
| تغيير السعر | `سعر الموجة 50` |
| تحديد الكمية (0 = نفدت) | `كمية الموجة 5` |
| نفدت / رجعت | `نفد الموجة` أو `متوفر الموجة` |
| تغيير الاسم | `اسم الموجة = الاسم الجديد` |
| الاسم بالإنجليزي | `انجليزي الموجة = Wave` |
| تغيير الوصف | `وصف الموجة = الوصف الجديد` |
| حذف منتج | `حذف منتج الموجة` |
| منتج جديد | صورة، وتحتها أربعة أسطر: `منتج` ثم الاسم ثم السعر ثم الوصف |
| تغيير صورة منتج | صورة، وتحتها `صورة الموجة` |
| صورة في «روح الفريق» | أي صورة مع نصها |
| تعديل نص صورة | عدّل تعليق الصورة في تيليجرام، أو ردّ عليها بـ `نص النص الجديد` |
| حذف صورة | ردّ على الصورة بكلمة `حذف` (أو `حذف` وحدها لحذف آخر صورة) |

البوت يرد على كل أمر بتأكيد. التغيير يظهر في الموقع خلال دقيقة تقريباً، والصفحات المفتوحة تتحدّث من نفسها بدون تحديث.

### كيف يعمل

GitHub Actions يشغّل `scripts/telegram-bot.mjs`، وهو يستمع للبوت باستمرار حتى التاريخ المكتوب في `LISTEN_UNTIL` داخل `.github/workflows/telegram-bot.yml` (حالياً 30 نوفمبر 2026). بعد هذا التاريخ يفحص البوت كل 5 دقائق فقط. التغييرات تُحفظ في `data/products.json` و `data/gallery.json` والصور في `assets/store/` و `assets/team/`.

## الحماية

- توكن البوت محفوظ كسرّ في GitHub ولا يظهر في الكود ولا في الموقع.
- البوت لا ينفّذ إلا أوامر رقم المحادثة المسجّل في `TELEGRAM_CHAT_ID`.
- الصفحات فيها سياسة أمان (CSP) تمنع تشغيل أي سكربت من خارج الموقع، وملفات GSAP الخارجية مقيّدة ببصمتها.
